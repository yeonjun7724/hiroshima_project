# Hiroshima fallback data

Downloaded 2026-08-26. Original source files are retained.

- `hiroshima_chome_population_2026_07.csv`: Hiroshima City official chome population CSV (CP932).
- `hiroshima_transport_*.csv`: Hiroshima transport facility CSVs mirrored by G-spatial Information Center.
- `gtfs/*`: current GTFS-JP feeds from Hiroshima Bus Association providers.
- `hiroshima_gtfs_stops_all.gpkg`: converted WGS84 point layer from every downloaded GTFS feed.
- `hiroshima_alternative_stations.gpkg`: JR and Astram station points converted from the city CSVs.

Source pages: https://www.city.hiroshima.lg.jp/shisei/toukei/1027844/1027845/1027846/1038151/index.html
https://www.bus-kyo.or.jp/gtfs-open-data
